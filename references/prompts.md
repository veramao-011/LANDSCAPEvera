# Prompt templates

Substitute the actual site, view, geometry and constraints. The text defines a reusable visual language rather than a fixed scene.

## Base

```text
Create [view type] of [site and design] for an architectural landscape portfolio.
Preserve [geometry, viewpoint, design features and crop] from the supplied project input.
Use precise fine blue-violet architectural linework, pale lavender shading, small pale-cyan accents and dominant white space. Primary edges are clearer than secondary details. Represent the sky using fine light horizontal hatching. Use sharp irregular vegetation with slender open branches, few leaves and sparse grasses. Keep spatial circulation and boundaries clearly readable.
No text, people, animals, vehicles, decorative props, cloud icons, stippled skies, dense foliage, fuzzy edges, paper texture or watercolor wash, unless explicitly requested. Keep necessary railings and other functional elements.
Context: [location, architecture, ecology]. Composition: [camera, spatial relationship, aspect ratio].
```

## Optional scene actions

- Entrance: show a clear transition from existing urban fabric to a riverside access threshold and planted buffer.
- Bridgehead: show an upper route connecting to a lower riverside route; retain supplied bridge geometry and make level changes legible.
- River bend: place a peripheral path away from the sensitive habitat core; do not introduce an unsourced crossing.
- Courtyard: express spatial enclosure, circulation and planted edges with legible ground planes and white space.
- Existing design: change visual treatment while preserving the design layout, structures and viewpoint.

When exact mapping preservation is requested, generate companion illustrations separately and use a suitable layout workflow to compose with the unchanged original map.
